### 同じ日に潰した「静かな壊れ方」（再発しやすい順）

いずれもテストは緑のまま、エラーも出さずに間違え続ける形だった。**値そのものではなく、値の運び方で壊れる**のが共通点。

| 何が | どう壊れていたか |
|---|---|
| 年齢の基準年 | `getFullYear()` が実行環境依存。**UTC の Cloud Run では JST 1/1 0:00〜9:00 に1歳ずれる**。4か所 → `src/time/jstYear.ts` に一本化 |
| AI の断り書き | 「検査を通らなかった」と固定表示。実際は**鍵が無効で1文字も届いていなかった**。退避理由で書き分けるよう修正 |
| 鍵の形式チェック | `AIza` で始まらない**有効な鍵**を、Google に聞く前に拒否していた。形の検査が静かな壊れ方を作っていた |
| 合言葉 | Secret Manager 由来の**末尾の改行**で永久に不一致。画面は「合言葉が違う」としか言わない |
| 出典リンク | 公的機関へのリンク**4本中2本が404**。「根拠を見せる」が芯なのに切れていた |
| 結果画面の KPI | 組み替え世帯で**不足側だけ**をオレンジ表示。見出しの結論と逆を向いていた |

> ⚠️ このURLは `--allow-unauthenticated`＝知っていれば誰でも開ける（noindex 済み）。**`verified:false` が残る検証ビルドなので、n1 の相手以外に配らない。**

**2026-08-31 午後に、出力の中身を大きく作り直した。** きっかけは「顧客にとっての価値が出せていない」という指摘と、FPの実務資料13点（FPキャプテン／FP相談サービスのサンプル）の分析。
