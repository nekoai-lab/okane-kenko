# okane-kenko デザインモック(参照実装) — 2026-09-21

Claude Design キャンバスで作った6画面を、ブラウザでそのまま開けるプレーンHTMLに変換したもの。
本番実装の見た目・文言・挙動の参照元。仕様の本文は `docs/redesign-spec-2026-09-21.md` を正とする。

## ファイル
- flow.html — 全体構成図(5ページ+URLクエリ状態設計)。実装前にまず読む
- lp.html — LP「うちの家計、大丈夫なんだろうか。」
- check.html — リスク別健康診断表(結果の玄関)。判定+精度ラベルの表
- result.html — 死亡の詳細(4 STEP)。前提3目盛りトグル・段差チャート・滝グラフ・数直線判定が vanilla JS で動く
- lab.html — もしもラボ。年齢スライダー・7シナリオ切替が動く。自然言語what-ifは静的モック
- roadmap.html — 保存(PDF/URL/.ics)・もしも比較表・見直しカレンダー。ボタンはダミー
- tokens.css — 色・字・角丸・意味色の定義(実装はここから読む)

## 実装時の注意
- ここは 1280px 固定の構成検証版。本番は 390px(スマホ)基準で組み直す
  (滝グラフ→縦積み / 段差チャート→数字カード3枚+ミニチャート / 比較表→カードスワイプ)
- 金額はすべてサンプル。エンジンの計算値に置き換える(仕様書§4・§6)
- result.html / lab.html の <script> 内の計算ロジックは、エンジンが返すべき値の形の見本でもある
- フォント: Shippori Mincho(見出し) + Zen Kaku Gothic New(本文)、Google Fonts
- 判定バッジ・精度ラベルの色対応は tokens.css の意味色コメントを正とする
