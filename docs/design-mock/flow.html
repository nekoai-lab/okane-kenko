全体構成 — 5ページと「診療記録」の流れ
読む → 答える → 読む → 触る → 残す。初回は一方通行(実線)、再訪は共通タブでどの部屋にも直行。この順路がそのまま2分デモの台本になります。
共通タブ「診断結果｜もしもラボ｜ロードマップ」 — 再訪はどの部屋にも直行(双方向)
読ませて、疑わせる
LP　/
「勧められたまま、になっていませんか」。多すぎ側の痛みで入る。売らない・言い切らないの宣言。
答える
ウィザード　/wizard
10問＋妻(配偶者)の年齢1問。「分からない」も答えになる。約3分。
読む
診断結果　/result
玄関は「リスク別診断表」(死亡・病気けが・就業不能・失業)。各項目の詳細(まず死亡)が縦1本: 答え→物語→計算→判定。上部に判定バッジが追従。
触る
もしもラボ　/lab
時期スライダー・シナリオ切替・言葉のwhat-if。AIは前提への翻訳のみ、計算は決定的エンジン。
残す = CV地点
ロードマップ　/roadmap
もしも比較・見直しカレンダー。PDF/URL/.icsのダウンロードを「成約」として計測。
状態 = URLクエリの「診療記録」(サーバもアカウントも持たない)
回答 ＋ 暮らし方の前提の目盛り ＋ もしもの差分(変更した前提だけ)。金額そのものは載せない。4ページが同じ器を読み書きし、URLコピー＝完全な保存＝再開。
初回導線 = 2分デモの台本
LP 10秒 → ウィザード早送り → 結果は段差チャートで止める → 前提トグルで判定を3回変える → ラボでwhat-if＋ガードレール表示 → .icsで締め。
実装は390px(スマホ)基準
滝グラフは縦積み、段差チャートは3枚の数字カード＋ミニチャート、もしも比較表はカードのスワイプに読み替える。この1280版は構成検証用。
バックエンドへの要求
試算エンジンは総額だけでなく年次キャッシュフロー(収入源別・支出別の配列)を返すこと。段差・タイムライン・ラボはすべてこの配列の別ビュー。
