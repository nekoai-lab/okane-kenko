## プロジェクト概要タブ

### プロジェクト名

```
お金の健康診断 ─ 万一のときに要るお金と、知らない制度を根拠つきで示す
```

### プロジェクト概要

```
保険のことがふと気になったとき、AIとの会話だけでは、その金額が何を根拠にしているのか、本当に正しいのかが分かりません。お金の健康診断は、10問ほど答えるだけで、万一のときに家族の生活費がどれだけ要るか、遺族年金など自分が知らなかった制度でどこまで賄えるか、いまの備えとの差を、計算の内訳と公的な出典つきで示します。保険を売らない立場で作っているので、足りない人には「準備が必要です」と、足りている人にはそのとおりに伝えられます。金額は算定エンジンだけが作り、Geminiは説明文だけを担当します。制度の改定は監視エージェントが毎週一次情報から見つけ、人の承認待ちに積みます。
```

## プロジェクト紹介タブ

### 課題と解決（543字／800字）

```
**課題**
保険のことがふと気になったとき、いまは AI に聞く人も増えました。けれど会話だけでは、その金額が何を根拠にしているのか、本当に正しいのかが分かりません。プランナーに相談しに行くのは重く、相談先の多くは保険を売る人が払い手です。
さらに、遺族年金などの公的な保障は多くの人が思うより手厚いのに、知られていません。知らないまま「足りるのか、足りないのか」を判断することになります。

**解決**
保険を売らない立場で作った、必要保障の診断です。
- 10問ほど答えると、万一のときに家族の生活費がどれだけ要るか、公的な制度でどこまで賄えるか、いまの備えとの差が、**計算の内訳と公的な出典つき**で出ます
- 足りない人には「準備が必要です」と、足りている人にはそのとおりに、どちらにも偏らずに伝えます
- 金額を作るのは算定エンジンだけです。Gemini は結果を平易な言葉にするだけで、数字は書きません
- 入力は「25〜30万円」のような幅で答えられ、結果も幅で返します。幅の中で結論が変わるときは、隠さず画面に書きます
- 制度の値は毎年変わります。監視エージェントが毎週一次情報を巡回してズレを見つけ、10世帯での影響と根拠の引用をつけて、人の承認待ちに積みます
```

### アーキテクチャ説明（761字／800字）

```
**構成**
- **Cloud Run**：Next.js 15（App Router）/ React 19 / TypeScript のアプリ本体。診断・結果画面・運営用の承認画面・監視エージェントが同居
- **Gemini API**：結果を平易な日本語にする役だけを担当
- **Firestore**：同意した世帯の記録、制度の変更提案、巡回の記録
- **Cloud Scheduler**：毎週月曜9時に監視エージェントを起動
- **Secret Manager**：APIキーと合言葉。コードにもリポジトリにも置かない
- **Cloud Build**：main への push で lint → 型チェック → テスト → デプロイ

**設計上の工夫**
- **金額を作るのは算定エンジンだけ**：外部に依存しない純粋関数で、制度の値は出典・有効期限つきの YAML から読みます。Gemini には数字を書かせず、{{金額}} のような差し込み口だけを書かせ、画面が計算結果を差し込みます。出力は機械的に検査し、落ちたら破棄します
- **AIに副作用を持たせない**：Gemini には書き込みや外部送信の手段を渡していません。監視エージェントが書けるのは、承認待ちの提案と巡回の記録だけです
- **自律監視は「積む」まで**：一次情報は許可リスト内の1ホップだけ取得し、金額は正規表現で取り出します。本文はAIに渡しません。ズレを見つけたら10世帯で再計算して承認待ちに積み、制度の値の反映は人が Pull Request で行います
- **壊れたら止まる**：期限切れの制度の値では診断を止めます。10世帯・70件のゴールデンテストが通らないと commit もデプロイもできません
```
