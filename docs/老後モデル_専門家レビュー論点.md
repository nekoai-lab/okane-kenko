# 老後モデル ─ 専門家レビュー論点（マージ前チェックリスト）

**対象**：ブランチ `feat/elderly-oldage-model`（ADR-016）。老後（配偶者65歳→平均寿命）の基本生活の不足を必要死亡保障に連続加算し、介護は別レイヤーで参考提示するモデル。
**目的**：**必要額が上がり「足りない」が増える**変更なので、恐怖訴求（芯に反する）になっていないか、算定・表現・法務を専門家で確認してからマージする。
**このファイルは論点の整理であり、決定ではない。**

---

## 1. 表現（保険業法・煽り）
- 「老後まで見ると足りない」を、**不安訴求でなく事実提示**として出せているか（芯：断定しない・煽らない）。
- GT-08 のように **sufficient→shortage に反転**する世帯で、「必要額は増えたが現在の保障で足りている（減らせる）」という**冷静な出し分け**ができているか（verdict と gap の分離）。
- 介護を「点の必要額」に入れず**別レイヤーの参考額**にした判断は、断定回避として妥当か。
- 保険業法上、必要保障額の提示が「特定商品の推奨」に読まれない線を越えていないか（弁護士 OI-01 と併せて）。

## 2. 算定の妥当性（一次情報で確定すべき値）
- **老後の年間不足 `annualDeficit`（現状 336,000円/年）**：家計調査（65歳以上・単身無職）の**消費支出**を一次情報で確定。可処分所得ベースか消費支出ベースかを明確に。
- **平均寿命 `lifeExpectancy`（現状 85）**：性別を集めないため単一値。男81/女87 の扱い（保守的に長寿側？ ブレンド？）を決める。
- **65歳以降の年金の単身移行**：遺族厚生年金と自分の老齢年金の差額調整を、家計調査の平均不足で代理してよいか（近似の妥当性）。
- **介護 `care`（一時47.2万・月9万・55ヶ月）**：生命保険文化センター 2024 の値。在宅/施設で分散が大きい点の但し書きが十分か。
- 老後不足を**全世帯一律**（約672万）で加算する粗さ。生活水準で老後不足も変わるはず（高支出世帯ほど大）— 一律で許容か、月生活費に連動させるか。

## 3. ゴールデン検算（正本＝算定テスト_10世帯.xlsx）
- 期待値が動くのは **GT-02・GT-06・GT-08** の3世帯（他7は不変）。特に **GT-08 の verdict 反転**を xlsx で引き直して確認。
- 確認後に `households.ts` を更新 → テスト green → マージ可。**コードで期待値を勝手に上書きしない**。

## 4. verified ゲート
- `elderly.verified` / `elderly.care.verified` は現状 `false`。一次情報確定まで本番（strictVerified）で停止する設計になっている（漏れ防止済み）。true 化は一次情報確認後。

---

## マージ可否の条件（すべて満たすまで保留）
1. 表現レビュー（保険業法・煽らない）を通過
2. 一次情報で `annualDeficit` / `lifeExpectancy` / `care` を確定し `verified:true`
3. GT-02/06/08 を xlsx 検算で確認し `households.ts` 更新
4. ADR-016 の「宿題」欄を消し込み
