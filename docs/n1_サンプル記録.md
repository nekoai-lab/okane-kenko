# n1 サンプル記録 ─ ⚠️ 架空・実施した実データではない

**位置づけ**：実 n1 が行われるまで**開発（特に T-07 AI言語化）を止めないための架空サンプル**。ゴールデンテストの架空世帯と同じ扱い。
**本番の GO/STOP 判定は、必ず実在の 2〜3 名で実施した n1 で置き換えること。** これはあくまで仮の GO。

判定基準は [`docs/H2_成功基準_n1.md`](./H2_成功基準_n1.md)。

---

## サンプル対象（架空・SPEC の対象＝既加入・未見直し層）

### N1-A：34歳・会社員・妻専業・子3歳・持家ローン団信あり（架空）
- 見た直後：「え、これ減らせるんだ」と自分の数字（減額余地）を声に出した。
- 「この額はなんで？」→ 支出の因数分解を見て「教育費と生活費か、なるほど」と根拠に納得。
- 行動：「保険の証券、家に帰って見てみる」と自分から。
- → **PASS 寄り**（自分事化＋根拠納得＋次の行動）。

### N1-B：41歳・共働き・子10歳・賃貸（架空）
- 「必要額」は理解したが、レンジ（約○〜○万）に少し戸惑い「結局いくら？」
- スライダーを触って「生活費でこんな変わるのか」と関心。時間軸（独立まで）に「あと12年か」と反応。
- 行動：「勤務先に団体保険あるか聞いてみる」。
- → **PASS 寄り**（but レンジの伝わり方に改善余地）。

### N1-C：29歳・独身（架空）
- 「自分は不要って出た、正直ホッとした」＝「入らなくていい」が伝わった（芯の価値）。
- 「分かること/分からないこと」で「家計全体じゃないのね」と期待値が合った。
- → **PASS**（煽られず、正直さが刺さった）。

## サンプル判定（仮 GO）
- 3人中3人で**結論の理解・自分事化・次の行動**が観察された（PASS サイン優勢）。
- 改善点：**レンジの伝え方**（N1-B が「結局いくら？」）。T-07 の AI 言語化で「レンジの読み方」を平易に補うと良い。
- → **仮 GO：AI言語化（T-07）の開発に進んでよい。** ただし本番判断は実 n1 で確定。

## この仮 GO が示す T-07 への要件（サンプル）
1. レンジを「約○〜○万円（幅がある理由：前提が動くから）」と平易に言語化する。
2. 結論（足りている/減らせる/足りない/要らない）を最初の一文で断定しすぎず「いまの前提では」を添える。
3. 数値は AI に作らせず、プレースホルダ（`{{necessaryAmount}}` 等）で受けてクライアントが差し込む（責務境界）。
