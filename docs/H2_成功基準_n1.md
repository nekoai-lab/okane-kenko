# H2 の成功基準と n1 台本（T-05 立ち止まり点）

**目的**：T-05a（AIなしの結果画面）を 2〜3 人に見せ、**「AIが無くても価値が届くか（H2）」を、定量ではなく発言・行動レベルの質的基準で判定する**（ADR-013）。
**原則**：この基準は n1 を**始める前に**確定させる。見た後に基準を動かさない（お手盛り防止）。

---

## 見せるもの
`/wizard` に本人の状況を入れてもらい、`/result`（T-05a）を一緒に見る。AIの言語化はまだ無い。

## 判定サイン（本人の発言・行動で見る）

### PASS＝AI実装へ進んでよい（下記が複数出る）
- 見せた直後、指示なしで**自分の数字**（必要額レンジ・不足/減らせる額）を読み上げ、「これは自分のことだ」と接続する。
- 結論（足りている／足す／減らせる／要らない）に対し、**次の行動**（現契約を見る・勤務先の窓口に聞く 等）を自分から口にする。
- **根拠に触れて納得する**（「この額はこういう理由か」と出典・前提を見て腹落ちする。鵜呑みでない）。
- 子のいる人は、**子の年齢での変化**に反応する（「うちはあと◯年か」と自分の時間軸に接続）。
- AIの説明文が無くても「これで十分わかる／納得した」と言い、追加説明を強く求めない。

### STOP＝AIに進まず設計に戻る（下記が出たら）
- 「で、結局どうすればいいの？」と、**結論の意味が伝わっていない**。
- 数字を見ても自分ごと化できず「難しい／よく分からない」で止まる。
- レンジ・前提・当社基準の但し書きに気を取られ、**不信・混乱**が起きる。
- 「足りない」の出し方が**不安・煽り**に感じられたと言う（芯に反する）。

## 決定ルール
- n=2〜3。**過半が STOP サイン（特に「結論の理解」）なら AI（T-07）に進まず設計に戻る**。
- PASS/STOP が割れたら、割れた原因（設問？結論の言い回し？根拠の見せ方？）を1つ特定してから再判定。

## n1 台本（15〜20分）
1. 前置き：「保険を売る場ではない。必要なら"入らなくていい"と言う診断です」と伝える。
2. `/wizard` を本人に触ってもらう（横で見る、口出ししない）。**詰まった設問・迷いを記録**。
3. `/result` を開く。**最初の30秒、こちらから説明せず**、本人が何を見て何を言うかを観察。
4. 問い（誘導しない）：
   - 「これを見て、まず何を感じましたか？」
   - 「この金額は、どうしてこの額だと思いますか？」（根拠が伝わっているか）
   - 「このあと、何かしようと思いますか？」（行動接続）
   - 「分かりにくかった所・引っかかった所は？」
5. 記録：PASS/STOP サインの該当、詰まった設問、"自分ごと化"の瞬間の有無。
