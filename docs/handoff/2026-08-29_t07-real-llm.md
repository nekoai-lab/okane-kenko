## このセッションでやったこと（PR #34・マージ済み）

スタブ（`narrateStub`）で示していた枠を、そのまま実 LLM に置き換えた。
**「AIはプレースホルダだけを書き、数値は算定結果から差し込む」という枠は変えていない。**

| ファイル | 役割 |
|---|---|
| `src/narrate/prompt.ts` | プロンプトの正本。**ベイクオフと本番で同じ文面**（コピーを持つと、採点したプロンプトと本番がズレる） |
| `src/narrate/gemini.ts` | AI Studio の `streamGenerateContent` を SSE で受ける。鍵はヘッダで渡す。鍵の形の検査もここ（bakeoff と共有） |
| `src/narrate/narrateStream.ts` | 検査ループ。HTTP も鍵も持たないので、**偽の生成器で事故を再現してテストできる** |
| `src/narrate/stream.ts` | 開きかけのプレースホルダ（`{{selfRa`）を閉じるまで表示しない |
| `app/api/narrate/route.ts` | NDJSON でテンプレを流す。**算定はサーバでやり直す**（クライアントの金額を信用しない） |
| `app/result/Narration.tsx` | 差し込みは画面側。退避したらその旨を画面に書く |

検査の順序には理由がある ── **G-1（生の数字）と未知プレースホルダは届いた時点で打ち切り**（画面に出す前に止める）、
**G-2/G-4/G-6 は全文がそろってから**（結論の一致は文が閉じないと判定できない）。

退避の条件：鍵が無い／形がおかしい・API が落ちた・20秒で返らない・検査に落ちた。
いずれもテンプレに切り替わり、画面に「定型文に切り替えました」と書く（沈黙で誤解させない）。
鍵が未設定なら**そもそも AI を呼ばない**。

E2E は実LLMを呼ばない（形の違うダミー鍵＋`page.route` で差し替え）。課金が出るうえ、生成文が毎回変わって落ち方が読めなくなるため。
