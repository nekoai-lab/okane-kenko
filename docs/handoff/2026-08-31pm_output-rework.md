## きっかけ

**「アウトプットというか、顧客にとっての価値がうまく出せてない」**という指摘。
参考としてFPの実務資料13点（`FBサンプル結果/`）を受け取った ── FPキャプテン（神奈川県FP協同組合）の
ライフプラン作成ツール、FP相談サービスのサンプル（保険の見直し・キャッシュフロー表・
バランスシート・教育費・住宅ローン・税金・ポートフォリオ・積立シミュ）。

## 分析でわかったこと

**FPの出力が厚いのは、扱う範囲が広いからではない。** 型が4つあるから。

1. **時間軸が主役**（ほぼ全ての成果物が40年分の表かグラフ）
2. **「いくら浮くか」を円で出す**（保険料の年額削減。保障額ではない）
3. **現状把握を先に**（「まずは現状把握が大切です」と資料に明記されている）
4. **現状 vs 改善後を2本並べる**

この4つは**範囲を広げなくても入れられる**。そこを実装した。

## いちばん効いた発見

結果画面は `projection` を import しておきながら「いちばん細いのは◯年ごろ」だけを出し、
残りを捨てていた。薄さの主因はこれ。

## 途中で見つけた「静かな壊れ方」

どれもエラーを出さないので、見なければ気づけなかった類。

- **`/` が T-02 時代のプレースホルダ（「準備中です」）のまま**で、本体への導線が1つも無かった。
  URLを直打ちしない限り誰も診断にたどり着けない ＝ 動いているのに動いていないように見える
- **ダークモードで本文が読めなかった。** トークンは反転させていたのに `body` に当てていなかったので、
  文字だけ明るくなり地はブラウザ既定の白のまま
- **結果画面に `<h1>` が0個**で、節見出しが全部 `<div>`。仕様書は4段階のタイポスケールを
  定義しているのに、実装は2段階しか使っていなかった。「縦に羅列」はマークアップそのものだった
- **CLAUDE.md の「専門用語は初出で1行注釈」が結果画面で守られていなかった。**
  「中高齢寡婦加算が始まる」がライフイベントに出るのに、何のことか画面のどこにも無い状態
- **`bakeoff-out/` が古いまま採点されかけていた**（午前に解消）

## 試してやめたこと（記録）

- **散文720px・図1,120pxの二段幅**：SVG は viewBox で伸縮するので、図を広げると軸の文字まで
  拡大されて崩れた。実際に幅を要したのは検査値パネル（4列）だけで、30本の棒も6列の表も720pxで足りる
- **年間収支のマイナスの棒を Warning（オレンジ）に**：同じ図に支出の折れ線（オレンジ）が
  同居していて系列が混ざった。棒は符号によらず1色にし、0の線に対する向きで伝える
- **必要額が0の世帯にグラフを出す**：棒が1本も立たず「壊れている」と読まれた。言葉で言い切る形に
- **要約に「判定＋過不足」を並べる**：「十分に足りています／約200万円 足りていません」という
  矛盾した1行になった。`verdict`（必要額の大きさ）と `gap`（いまの保障との差）は別の話

## 🔴 残っている判断（人が決めること）

### 1. ふだんのライフプラン図を作るか（FP比較で残った唯一の差）

`projectDeath` はあるが**生存シナリオは未実装**。`docs/SPEC.md` が「未決（2026-08-30）」として
明記しているとおり、広げると**「家計全体の最適化は扱わない」という画面で宣言している線引きを
引き直す**ことになる。追加設問は退職金と毎月の積立額の2問だけ。
**表の質ではFPに並んだ／部分的に勝ったが、扱う範囲は意図的に負けたまま。**

### 2. ADR が3件たまっている（いずれも人間の確認が要る）

- **ADR-017**：AI言語化のモデル選定 ← **盲検採点が未着手**。`bakeoff-out/` は 8/31 に回し直し済み
- **ADR-018**：主グラフのウォーターフォール化（2026-08-30 のデザイン規定変更）
- **ADR-019**：デザインシステムを Airbnb へ（ライト固定・Rausch）。**文案は 8/31 のセッションに出してある**

### 3. 保険料を聞くか（提案3）

いまは保障額しか聞いていないので「年◯万円浮く」が出せない。FPの見直し資料の最上段は
**年間保険料の削減額**で、そこがいちばん実感される数字。ただし T-04 は最大の離脱点なので、
**設問を1問増やす判断**が要る。

### 4. カードの中に残っている表現の緊張

「上乗せの保障は要りません」の直後に「約200万円 足りていません」が出る世帯がある
（`verdict: ample` かつ `gap: shortage`）。既存の設計（金額の呼び名と注記で説明）なので今回は
触っていない。n1 で読み手が混乱するようなら直す。
